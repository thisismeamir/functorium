A Desktop manager that holds onto two things
1. There's no such thing as a workspace. There are only windows tiled in a canvas.
2. A blank place have a default initialization so that new apps and stuff can be added to it. 

For bars, panels, etc we can have a `scope` view that let's you adjust things. and a `fast-scope` that let's you adjust things quickly. I would design it as I find time someday. 

Application launching and openning new things should be more dynamic than opening a launcher and typing.

- How to resize and fit things into a single monitor? (since there's no such thing as workspace in this idea)
- Window border and menus
- Floating windows

**Panels**
- Notification Centers

**Dock/Bar**
