# KAGE
## Context
KAGE (Kernel of Autonomous Graph-based Execution), is a software that would allow users to make automation workflows, based on events, or fetching different sources (both online, and offline).
## Description
The central idea is to have a repository of usable scripts, and produce graphs that would execute these scripts with different data and after a specific source/event has been triggered.
