# Theory
## Time-Independent Schrödinger Equation

The time-independent Schrödinger equation in one dimension is:

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$$

This is an eigenvalue problem where:

- $\psi(x)$ is the wavefunction
- $E$ is the energy eigenvalue
- $V(x)$ is the potential energy
- Solutions exist only for certain discrete values of $E$

## Finite Difference Approximation

We discretize space into steps of size $\Delta x$, with $\psi_n \equiv \psi(n\Delta x)$. The second derivative becomes:

$$\frac{d^2\psi}{dx^2} \approx \frac{\psi_{n+1} + \psi_{n-1} - 2\psi_n}{(\Delta x)^2}$$

This gives us the recurrence relation:

$$\psi_{n+1} = 2\psi_n - \psi_{n-1} - 2(\Delta x)^2(E - V_n)\psi_n$$

where we set $\hbar = m = 1$ in atomic units.

## Boundary Conditions and Parity

For symmetric potentials, we exploit parity:

**Even parity solutions:**

- $\psi(0) = 1$ (normalized arbitrarily)
- $d\psi/dx|_{x=0} = 0$ → $\psi_{-1} = \psi_1$

**Odd parity solutions:**

- $\psi(0) = 0$
- $d\psi/dx|_{x=0} = 1$ → $\psi_{-1} = -\psi_1 + 2\Delta x$

# Shooting Method

1. Start with an initial energy guess $E$
2. Integrate the wavefunction from $x=0$ outward using the recurrence relation
3. Check if $|\psi|$ diverges (exceeds cutoff parameter $b$)
4. If $\psi$ diverges:
    - If divergence direction differs from previous iteration: reverse direction and halve $\Delta E$
    - Update: $E \leftarrow E + \Delta E$
5. Repeat until $|\Delta E|$ is smaller than tolerance

## Core Shooting Method Implementation


```python
class SchrodingerSolver:
    """
    Solver for 1D time-independent Schrödinger equation using shooting method.
    """

    def __init__(self, N: int = 200, delta_x: float = 0.01,
                 cutoff: float = 1.5, min_delta_E: float = 1e-5):
        """
        Parameters:
        -----------
        N : int
            Number of spatial grid points
        delta_x : float
            Spatial step size
        cutoff : float
            Divergence threshold parameter
        min_delta_E : float
            Convergence criterion for energy
        """
        self.N = N
        self.delta_x = delta_x
        self.cutoff = cutoff
        self.min_delta_E = min_delta_E
        self.x = np.arange(0, N * delta_x, delta_x)

    def potential(self, x: np.ndarray, V_func: Callable) -> np.ndarray:
        """Apply potential function to spatial grid"""
        return V_func(x)

    def initialize_wavefunction(self, parity: str = 'even') -> np.ndarray:
        """
        Initialize wavefunction with appropriate boundary conditions.

        Parameters:
        -----------
        parity : str
            'even' or 'odd' parity solution
        """
        psi = np.zeros(self.N)

        if parity == 'even':
            # Even parity: psi(0) = 1, psi'(0) = 0
            psi[0] = 1.0
            psi[1] = 1.0  # psi(-1) = psi(1) for derivative = 0
        elif parity == 'odd':
            # Odd parity: psi(0) = 0, psi'(0) = 1
            psi[0] = 0.0
            psi[1] = -self.delta_x  # psi(-1) = -psi(1) + 2Deltax for derivative = 1
        else:
            raise ValueError("Parity must be 'even' or 'odd'")

        return psi

    def propagate_wavefunction(self, psi: np.ndarray, E: float,
                               V: np.ndarray) -> Tuple[np.ndarray, int, bool]:
        """
        Propagate wavefunction using finite difference method.

        Returns:
        --------
        psi : np.ndarray
            Wavefunction values
        divergence_index : int
            Index where divergence occurred
        diverged : bool
            Whether wavefunction diverged
        """
        diverged = False
        divergence_index = self.N - 1

        for i in range(1, self.N - 1):
            # Recurrence relation
            psi[i+1] = (2 * psi[i] - psi[i-1] -
                       2 * (E - V[i]) * self.delta_x**2 * psi[i])

            # Check for divergence
            if abs(psi[i+1]) > self.cutoff:
                diverged = True
                divergence_index = i
                break

        return psi, divergence_index, diverged

    def solve(self, V_func: Callable, E_initial: float,
              delta_E_initial: float = 0.1, parity: str = 'even',
              max_iterations: int = 1000, verbose: bool = False,
              store_history: bool = True) -> ShootingResult:
        """
        Solve Schrödinger equation using shooting method.

        Parameters:
        -----------
        V_func : Callable
            Function that returns potential V(x)
        E_initial : float
            Initial energy guess
        delta_E_initial : float
            Initial energy step size
        parity : str
            'even' or 'odd' parity
        max_iterations : int
            Maximum number of shooting iterations
        verbose : bool
            Print progress information
        store_history : bool
            Store intermediate results for visualization
        """
        # Initialize
        V = self.potential(self.x, V_func)
        E = E_initial
        delta_E = delta_E_initial
        last_diverge_sign = 0

        # Storage for history
        energy_history = [E]
        psi_history = []
        divergence_points = []

        iteration = 0
        converged = False

        while abs(delta_E) > self.min_delta_E and iteration < max_iterations:
            # Initialize wavefunction
            psi = self.initialize_wavefunction(parity)

            # Propagate wavefunction
            psi, div_idx, diverged = self.propagate_wavefunction(psi, E, V)

            if store_history and iteration % 5 == 0:  # Store every 5th iteration
                psi_history.append(psi.copy())
                divergence_points.append(div_idx)

            # Determine sign of divergence
            current_diverge_sign = np.sign(psi[div_idx] if diverged else psi[-1])

            # Adjust energy
            if current_diverge_sign != last_diverge_sign and last_diverge_sign != 0:
                # Changed direction: reverse and halve delta_E
                delta_E = -delta_E / 2.0

            E = E + delta_E
            energy_history.append(E)
            last_diverge_sign = current_diverge_sign

            iteration += 1

            if verbose and iteration % 50 == 0:
                print(f"Iteration {iteration}: E = {E:.6f}, DeltaE = {delta_E:.6e}")

        # Final calculation with converged energy
        psi = self.initialize_wavefunction(parity)
        psi, div_idx, diverged = self.propagate_wavefunction(psi, E, V)

        # Normalize wavefunction
        psi = self.normalize_wavefunction(psi)

        converged = abs(delta_E) <= self.min_delta_E

        if verbose:
            status = "Converged" if converged else "Max iterations reached"
            print(f"\n{status} after {iteration} iterations")
            print(f"Final energy: E = {E:.6f}")

        return ShootingResult(
            psi=psi,
            x=self.x,
            energy=E,
            iterations=iteration,
            converged=converged,
            energy_history=energy_history,
            psi_history=psi_history,
            divergence_points=divergence_points
        )

    def normalize_wavefunction(self, psi: np.ndarray) -> np.ndarray:
        """Normalize wavefunction using trapezoidal rule"""
        norm = np.sqrt(np.trapezoid(psi**2, dx=self.delta_x))
        if norm > 0:
            return psi / norm
        return psi
```

# Infinite Square Well

## Problem Setup

The infinite square well has potential: $$V(x) = \begin{cases} 0 & |x| < L \ \infty & |x| \geq L \end{cases}$$

Analytical eigenvalues: $E_n = \frac{n^2\pi^2\hbar^2}{8mL^2}$ for $n = 1, 2, 3, ...$


```python
def infinite_square_well(x, L=1.0, V0=1000):
    """
    Infinite square well potential.

    Parameters:
    -----------
    x : np.ndarray
        Spatial coordinates
    L : float
        Half-width of the well
    V0 : float
        Height of potential barriers (simulating infinity)
    """
    V = np.zeros_like(x)
    V[x > L] = V0
    return V

# Analytical solution for comparison
def analytical_energy_infinite_well(n, L=1.0):
    """Analytical energy levels for infinite square well"""
    return (n * np.pi)**2 / (8 * L**2)

# Create solver
solver = SchrodingerSolver(N=200, delta_x=0.01, cutoff=1.5, min_delta_E=1e-6)

# Find first few energy levels
print("=" * 60)

print("=" * 60)

results_infinite = []
parities = ['even', 'odd', 'even', 'odd']
initial_guesses = [1.2, 4.5, 10.0, 18.0]

for n, (parity, E_guess) in enumerate(zip(parities, initial_guesses), 1):
    print(f"\n--- Finding energy level n={n} ({parity} parity) ---")

    result = solver.solve(
        V_func=lambda x: infinite_square_well(x, L=1.0),

    print(f"Numerical energy:  E_{n} = {result.energy:.6f}")
    print(f"Analytical energy: E_{n} = {E_analytical:.6f}")
    print(f"Relative error: {error:.4f}%")

    results_infinite.append((result, n, parity))
```

# Finite Square Well With Barrier

## Problem Setup

A square well with a central barrier: $$V(x) = \begin{cases} V_0 & |x| < w/2 \ 0 & w/2 < |x| < L \ V_{wall} & |x| \geq L \end{cases}$$


## Solving Numerically


```python
def square_well_with_barrier(x, L=1.0, barrier_width=0.2, barrier_height=10.0, V_wall=20):
    """
    Square well with central barrier.

    Parameters:
    -----------
    x : np.ndarray
        Spatial coordinates
    L : float
        Half-width of the well
    barrier_width : float
        Half-width of central barrier
    barrier_height : float
        Height of central barrier
    V_wall : float
        Height of outer walls
    """
    V = np.zeros_like(x)

    # Central barrier
    V[np.abs(x) < barrier_width] = barrier_height

    # Outer walls
    V[x > L] = V_wall

    return V

# Solve for finite well with barrier
```

# Power-Law Potential

## Problem Setup

Investigate the power-law potential: $$V(x) = x^n$$

For large $n$, this approximates an infinite square well.


```python
def power_law_potential(x, n=2, x_max=2.0, V_wall=1000):
    """
    Power-law potential V(x) = x^n

    Parameters:
    -----------
    x : np.ndarray
        Spatial coordinates
    n : int
        Power exponent
    x_max : float
        Maximum x value before applying wall
    V_wall : float
        Wall potential
    """
    V = np.abs(x)**n
    V[x > x_max] = V_wall
    return V
```
