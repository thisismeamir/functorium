Let $C[a, b]$ denote the set of all real-valued continuous functions on the interval $[a, b]$. If f and g are continuous functions on $[a, b]$, then the vector addition and scalar multiplication are defined by

$$(f + g)(x) = f(x) + g(x)$$
and 
$$(\lambda f)(x) = \lambda f(x)$$

where $\lambda \in R$. Then $C[a, b]$ is a vector space with respect to the above operations over the field R.
