# Intuition

Two points of a topological space $X$ are topologically indistinguishable if they have exactly the same neighborhoods. That is , if $x$ and $y$ are points in $X$, and $N_{x}$ is a is the set of all neighborhoods that contain $x$, and $N_{y}$ is the set of all neighborhoods that contain $y$ then $x$ and $y$ are topologically indistinguishable,.

Basically we can not find a way to construct an open set that only contains one of these points. These two points are topologically indistinguishable if the topology of $X$ is unable to discern between the points.

Obviously, two points are topologically distinguishable if they are not topologically indistinguishable. This means there is an open set containing precisely one of the two points (equivalently, there is a closed set containing precisely one of the two points). This open set can then be used to distinguish between the two points.
