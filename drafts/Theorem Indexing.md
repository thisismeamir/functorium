1. Each model has a name: Topology ...
2. Take the acronym: Top
3. Add TH for theorem, PR for proposition, CO for corollary, LE for Lemma.
4. Next to a title that explains the theorem.
5. Each theorem has a formal definition, a logical statement to be written in form of latex. This is to be used for searching.
6. Each theorem then has the statement and the proof, A proof is a line by line argument of what we do at each point. If we'd used other theorems or lemmas or other things we would link them as well to keep track of them.
7. We add tags to the note so we can search them more easily

## How to tag?

One tag for the subject, up to three tags for each subtitle (topology -> connectedness -> ...)

Other tags also may apply.


# How to store them?

We Have them the same place we have atoms of a subject. But since theorems are being used inside other atoms, they can also be lost, so we make a list object of all the theorems, lemmas, etc that we have in a model as well.
