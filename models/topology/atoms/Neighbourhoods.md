# Intuition

A neighbourhood is one of the basic concepts in a topological space. It is closely related to the concept of open set and interior. Intuitively speaking, a neighbourhood of a point is a set of points containing that point where one can move some amount in any direction away from that point without leaving the set.

# Definition

Suppose $\mathcal{T}$ gives a topology to $X$. $N$ is a neighbourhood of a point $x \in X$ if $N$ is a subset of $X$ and $N$ contains some (at least one) open set $U_{i}$ to which $x$ belongs. The subset $N$ doesn't need to be open. If $N$ happens to be an open set in $\mathcal{T}$, it is called and open neighbourhood.
