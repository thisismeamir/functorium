# Definition

An equivalence relation is a binary relation that is reflexive, symmetric, and transitive. A binary relation $\sim$ on a set $X$ is said to be an equivalence relation if it is reflexive, symmetric, and transitive. That is, for all $a,b$ and $c$ in $X$:

- $a \sim a$ (reflexive)
- $a \sim b \iff b\sim a$ (symmetric)
- if $a \sim b$ and $b\sim c$ then $a\sim c$ (transitive)

$X$ together with the relation $\sim$ is called a [[Setoid]]. The equivalence class of $a$ under $\sim$, denoted $[a]$, is defined as $[a]=\{ x \in X:x\sim a \}$
