# Trivial Topology

Let *Y* be any set. Let $\mathcal{T} = \{\emptyset, Y\}$, where $\emptyset$ denotes the empty set and $Y$ is the entire set itself.

This is called the trivial topology on *Y*.

Formally:

The only open sets in this topology are the empty set and the set *Y* itself.
