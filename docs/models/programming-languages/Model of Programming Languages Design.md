Designing programming languages is theory, exercise and aesthetic. In this model we would investigate the topic in its practical designing perspective. This model is mainly discussing things that are needed to be considered or perhaps understood before implementing and designing a language from scratch. For more theoretical topics one can refer to the other model [[Model of Theory of Programming Languages]]

- **Syntax**
  *Syntax*, in a broad sense, concerns what programs *look like* without considering their semantics (what they mean). This is closely related to grammars of natural languages.
  
  These mandate or describe how to correctly construct texts in a language, but do not describe what these texts mean.
