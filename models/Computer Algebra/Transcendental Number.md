# Transcendental Number

> [!IMPORTANT] Definition
> A number $n$, or more generally any algebraic object, is said to be transcendental over a ring $R$ if there is no non-zero polynomial $p$ with coefficients in $R$ such that $p(n)=0$

“Transcendence is a deep mathematical question with implications for the decidability of computer algebra” ([pdf](zotero://open-pdf/library/items/PNABCSB9?page=20&annotation=6IIAPRGH))
