Let us start bu defining a vector space denoted $V^*$. The objects of this vector space are functions $v^*_i \in V^* : V \rightarrow \mathbb K$ where $\mathbb K$ is the field over which vector space $V$ exists. $V^*$ itself is a vector space over field $\mathbb K$ therefore by default we have, all the properties of a vector space (the addition, multiplication, and their properties), in $V^*$ as well.

Suppose then, we have a set of Basis, $B^*=\{\epsilon^i\}$ that spans $V^*$ and the elements are linearly independent.
