# Discrete Topology

Let *X* be any set. Let $\mathcal{T} = \mathcal{P}(X)$, where $\mathcal{P}(X)$ denotes the power set of *X* (the set of all subsets of *X*).  In this topology, every subset of *X* is open.

This is called the discrete topology on *X*, and (*X*, $\mathcal{T}$) is called a discrete space.

Formally:

For any $A \subseteq X$, we have $A \in \mathcal{T}$.

Therefore, for any $x \in A$, every subset of *X* containing *x* (including *A* itself) satisfies the condition that *x* is in a neighborhood contained entirely within *X*.  This holds because every set is open.
