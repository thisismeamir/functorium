# Definition

The set of all equivalence classes in $X$ with respect to an [[../set-theory/Equivalence Relation|Equivalence Relation]] $R$ is denoted as $X/R$, and is called $X$ modulo $R$ (or the quotient set of $X$ by $R$),  The surjective map $x \mapsto[x]$ from $X$ onto $X/R$, which maps each element to its equivalent class, is called the canonical surjection, or the canonical projection.
