# Data Science
## Overview
### Defining Data Science
Data science can be defined in few ways,  
1. It's coding, math, and statistics in applied settings.
2. The analysis of diverse data
3. Inclusive analysis
Data science takes unstrctured data then finds order, meaning and value.
Data science provides insight & competetive advantage.

## General Steps of DS
### Planning
1. Defining goals
2. organizing resources
3. coordination of people and resources
4. schedule project
### Data Prep
1. Get the data
2. Clean the data
3. Explore data
4. Refine data
### Modeling
1. Create model
2. Validate model
3. Evaluate model (interpret)
4. Refine model
### Follow Up
1. Present model
2. Deploy model
3. Revisit model
4. Archive assets

## Roles in Data Science
### Engineer
- Focus on back end, hardware, software.
- Makes DS possible
- Developers, DBA
### Big Data Specialists
- Focus on computer science and math
- Machine learning
- Data products
### Researchers
- Domain specific research
- Physics, genetics
- Strong statistics
### Analyst
- Day to day tasks
- Web analytics, SQL
- Good for business
### Business
- Frame business relevant quesitons
- manage projects
- must "speak data"
### Entrerpreneuer
- Data startups
- Needs of the business
