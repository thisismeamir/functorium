# Definition

Let $X$ and $Y$ be [[../topology/atoms/Definition of a Topological Space|Topological Spaces]]. A map $f:X\to Y$ is continuous if the inverse image of an open set in $Y$ is an open-set in $X$.

This definition is in agreement with our intuitive notion of continuity. Another important topic in continuity would be to consider the topological itself and proving that it would be continuous.
