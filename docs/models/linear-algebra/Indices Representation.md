
In some contexts, particularly in physics and tensor analysis, a more compact notation is used involving upper and lower indices. This notation often relies on the Einstein summation convention, which states that repeated indices are implicitly summed over.

Vectors in a vector space are usually, uniquely defined by a set of basis vectors $\mathbf e_i \in B$, which are linearly independent and span the vector space $V$.

In this sense and using the Einstein notation we can write a vector as:

$$
\mathbf v = v^i \mathbf e_i
$$
Therefore, noting for vector $\mathbf v$:

- The $i$th component of $[\mathbf v]_B$ is shown as $v^i$ with upper indices.
- The $i$th basis vector is shown as $\mathbf e_i$ with lower indices.
